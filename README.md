# RIFT

**Robotics Intelligence Framework and Toolchain**

RIFT is a reusable robotics and Physical AI platform for building,
simulating, training, evaluating, and deploying intelligent robot
applications.

RIFT is a library. Applications install RIFT into their own Python
environment. RIFT does not create or own an application environment.

IRIS is the first reference application built on RIFT.
